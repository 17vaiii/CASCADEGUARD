# Handoff contracts

These files define stable interfaces between the independently owned work
areas. Update a contract before changing a producer or consumer. Contract
changes should be reviewed by Person 3, the integration owner.

- [Cascade scenarios](CASCADE_SCENARIOS.md): Person 1 simulator -> Person 2 ML.
- [Cascade predictions](CASCADE_PREDICTION.md): Person 2 ML -> Person 3 platform.
- [Theft load vector](THEFT_LOAD_VECTOR.md): Person 4 -> Persons 1, 2, and 3.
