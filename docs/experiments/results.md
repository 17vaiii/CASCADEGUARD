## Setup

* Train runs: seeds 1000–1029 (30 runs); validation (threshold selection): 2000–2009 (10); test: 3000–3029 (30). Splits are grouped by run (no run appears in two splits).
* Unit of evaluation: 24 h window ending at the end of each simulated day (14 per run); label 1 if a theft-like event is active >= 12 of the 24 h, 0 if none, windows with 1-11 active hours are excluded.
* Test windows: consumer: 125829 windows, 1875 positive; dt: 4920 windows, 1523 positive; feeder: 1626 windows, 799 positive.
* Rules use their configured thresholds (score 1.0); ML methods use the threshold that maximised F1 on the validation runs. Isolation Forest is trained without labels; only its threshold uses validation labels.
* 95 % confidence intervals: cluster bootstrap over test runs (300 resamples).
