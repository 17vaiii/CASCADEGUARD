# Secure operation and remedial action principles

## N-1 security
A transmission system is normally operated so that the loss of any single element (one line, transformer or generator) does not overload the remaining elements or violate voltage limits. When a contingency leaves the system insecure, operators restore security with remedial actions before a second event or a relay operation can start a cascade.

## Order of remedial actions
Remedial actions are usually tried from least to most disruptive: first redispatch of generation and changes to interchange schedules, then topology changes such as switching, and only then controlled load shedding. Controlled shedding is preferred to uncontrolled loss because it is smaller, targeted and restorable.

## Verification before action
A proposed action should be checked against a power-flow model of the post-contingency state, because a change that relieves one line can overload another. Families of reliability standards such as the NERC Transmission Operations (TOP) and Emergency Preparedness and Operations (EOP) standards require operators to act on studied plans; this project mirrors that by re-simulating every recommendation.

## Human authority
Decision-support tools advise; the system operator decides and remains accountable. Recommendations must state their assumptions, their verification result and their uncertainty.
